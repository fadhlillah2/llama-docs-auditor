# Logs Folder Organization

This directory contains organized log files for the RAG Contract Advisor system.

## 📁 Directory Structure

```
logs/
├── README.md                    # This file
├── backend/                     # Backend server logs
│   └── app.log                 # Flask application logs
├── evaluation/                  # Evaluation pipeline logs
│   └── evaluation_pipeline.log # RAG evaluation logs
├── performance/                 # Performance benchmarking logs
│   └── (auto-generated)        # Benchmark execution logs
└── automation/                  # Automated task logs
    └── (auto-generated)        # Scheduled task logs
```

## 📋 Log Categories

### Backend Logs (`logs/backend/`)
- **app.log**: Flask server logs, API requests, errors
- Contains: HTTP requests, application errors, startup/shutdown events
- Rotation: Enabled (max 10MB, 5 backup files)

### Evaluation Logs (`logs/evaluation/`)
- **evaluation_pipeline.log**: RAG evaluation pipeline logs
- Contains: Evaluation metrics, pipeline status, error tracking
- Used by: `tests/evaluation/automated_evaluation.py`

### Performance Logs (`logs/performance/`)
- **benchmark_*.log**: Performance benchmarking execution logs
- Contains: Query response times, resource usage, benchmark results
- Auto-generated by: `tests/performance/benchmark_rag.py`

### Automation Logs (`logs/automation/`)
- **automated_task_*.log**: Scheduled automation logs
- Contains: Trend analysis, scheduled evaluations, alerts
- Auto-generated by: Automated evaluation pipelines

## 🔧 Configuration

### Environment Variables
```bash
# Backend logs location
LOG_FILE=logs/backend/app.log

# Log level
LOG_LEVEL=INFO  # DEBUG, INFO, WARNING, ERROR, CRITICAL

# Log rotation settings
LOG_ROTATION=True
LOG_MAX_SIZE=10    # MB
LOG_BACKUP_COUNT=5
```

### Log Formats
- **Timestamp**: `YYYY-MM-DD HH:MM:SS,sss`
- **Format**: `%(asctime)s - %(levelname)s - %(message)s`
- **Console**: Same format as file logs

## 🧹 Log Maintenance

### Cleanup Commands
```bash
# Clean old log files (>30 days)
find logs/ -name "*.log" -mtime +30 -delete

# Compress large log files
find logs/ -name "*.log" -size +10M -exec gzip {} \;

# View log sizes
du -sh logs/*/*
```

### Monitoring
```bash
# Watch backend logs in real-time
tail -f logs/backend/app.log

# Watch evaluation logs in real-time
tail -f logs/evaluation/evaluation_pipeline.log

# Search for errors
grep -r "ERROR" logs/
```

## 📊 Log Analysis

### Common Patterns
- **RAG Pipeline**: Look for "RAG EVALUATION" in evaluation logs
- **Performance**: Check response times and success rates
- **Errors**: Search for "ERROR" or "Exception" patterns
- **API Requests**: Monitor HTTP status codes in backend logs

### Example Commands
```bash
# Count evaluation runs
grep "✅ Evaluation completed" logs/evaluation/evaluation_pipeline.log | wc -l

# Find slow queries (>10s)
grep "response time" logs/performance/benchmark_*.log | grep -E "[0-9]{2,}\."

# Monitor error rates
grep -c "ERROR" logs/backend/app.log
```

## 🚨 Troubleshooting

### Common Issues
1. **Missing log directories**: Auto-created by application
2. **Permission errors**: Ensure write access to logs folder
3. **Disk space**: Monitor log sizes and implement cleanup
4. **Log rotation**: Check if rotation is working properly

### Recovery
```bash
# Recreate log structure if needed
mkdir -p logs/{backend,evaluation,performance,automation}

# Fix permissions
chmod 755 logs/
chmod 644 logs/*/*.log

# Test logging
echo "Test log entry" >> logs/backend/test.log
```
